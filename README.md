# Retail Game Platform

Plataforma web gamificada de simulação de gestão operacional de loja.

## Sobre o Projeto

Sistema multiplayer em tempo real onde equipes competem gerenciando lojas virtuais. Cada time toma decisões operacionais (estoque, pricing, equipe, investimentos) e o sistema calcula automaticamente o impacto financeiro (EBITDA) ao final de cada rodada.

Desenvolvido como projeto da **Residência em Software II** — Squad 14.

## Stack

- **Backend:** NestJS + Prisma + PostgreSQL + Socket.io
- **Frontend:** Next.js + Tailwind CSS + shadcn/ui
- **Linguagem:** TypeScript
- **Auth:** JWT + Refresh Token
